Job Form Autofill

Your details stay in this browser. Fill them once, then click “Autofill application” on any application (or use the toolbar button / ⌥⇧F).

Work authorization

List every country where you can work. Questions are answered for the country they name, or the job's country, or your home country. For any country not listed, the answers are “not authorized” and “will need sponsorship”.

Documents

Uploaded to file fields on the application. PDF recommended.

Resume
No file
Cover letter (optional)
No file

Saved answers

Answers to recurring questions. When you answer a question yourself on an application and submit, it's added here automatically (marked learned). Edit or remove anything that shouldn't be reused.

Settings & field detection

With a TypeSafe API key, each field is classified by Jev, which reads its label and context and picks the matching profile item or dropdown option. Without a key, pattern matching is used. With Jev on, your profile values, relevant saved answers, and the job's title/company/location (not your files) are sent to TypeSafe for each autofill.

Backup

Export everything, including documents, to a JSON file, or restore from one.
